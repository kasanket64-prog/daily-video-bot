# Milo & Pip pilot artwork

Original artwork created for this project using the built-in image generation tool:

- Milo: apricot bunny in mint overalls, yellow pocket, welcoming expression.
- Milo worried: same character and costume, gently puzzled expression.
- Pip: small lavender bird, golden beak and feet, friendly eyes.
- Garden: pastel clay-toy garden, open grassy stage, peach cottage, flowers.
- Bush: low rounded green bush with pink flowers, transparent background.

The original character and bush PNGs preserve alpha transparency. The renderer only trims transparent margins and composites them into moving scenes. No CoComelon characters, video clips, recordings, branding, or melodies are included.

These are reusable illustration assets for 2D puppet animation. They are not a rigged 3D character model. Speech is produced with Edge TTS; the quiet bell soundtrack is synthesized by the renderer from an original note pattern.
